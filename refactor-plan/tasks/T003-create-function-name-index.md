# T003: Create the function-name index

**Phase:** 1, Foundations · **Depends on:** — · **Lane:** C · **Size:** S

## Goal

`docs/FUNCTION_NAMES.md` lists every function name in the package sources,
alphabetically ignoring case (GUIDE §8.5). It is generated by the plan's
script, so later tasks can regenerate it.

## Files

- In scope (may edit, create or delete): `docs/FUNCTION_NAMES.md` (new).
- Context (read, do not edit): `refactor-plan/tools/function-names.mjs`,
  `refactor-plan/DECISIONS.md` D-24.
- Every other file is out of scope. Do not touch it, even to fix something
  that is obviously wrong. Write it in the notes column of PROGRESS.md instead.

## Rules and recipes

- R-104: "Keep a function-name index (for example `docs/FUNCTION_NAMES.md`) in alphabetical order, ignoring case. Check it before you name a function and reuse its words. Add every name you add and remove every name you delete."
- No recipe.

## Current state

`docs/FUNCTION_NAMES.md` does not exist.
`node refactor-plan/tools/function-names.mjs --check` prints
`docs/FUNCTION_NAMES.md is out of date; run with --write` and exits 1.

## Steps

1. Run `node refactor-plan/tools/function-names.mjs --write`. It prints
   `wrote docs/FUNCTION_NAMES.md: 1401 names from 664 files`.
2. Do not edit the generated file by hand.

## Must not change

Every file other than `docs/FUNCTION_NAMES.md`. In particular, do not edit
`refactor-plan/tools/function-names.mjs`.

## Acceptance criteria

- [ ] Step 1 printed `wrote docs/FUNCTION_NAMES.md: 1401 names from 664 files`.

- the script prints a different number of names or files (the package sources
  differ from the baseline);
- the script fails.

If you stop, delete `docs/FUNCTION_NAMES.md`, set the task to `blocked` in
PROGRESS.md with a one-paragraph reason, and stop.

## Finish

Set the task to `done` in PROGRESS.md, then commit `docs/FUNCTION_NAMES.md` and
`refactor-plan/PROGRESS.md` together with the message
